# Telegram Media Suite

نظام مستقل، الإصدار `3.1.0`، يجمع واجهة ويب محلية وبوت Telegram لتنزيل وسائط رسائل Telegram وتنظيمها حسب اسم القناة والشهر، مع طابور أتمتة ثنائي لمعالجة عدة روابط ووسائط بأمان.

## ما يفعله النظام

عند التشغيل يفتح خادمًا محليًا على `http://127.0.0.1:8765` ويفتح الرابط تلقائيًا في المتصفح. من الواجهة يمكن حفظ مفاتيح Telegram، اختيار مسار التخزين، تحديد مجلد الجلسات، تسجيل الدخول بالحساب الشخصي، تنزيل رابط رسالة، وتشغيل البوت أو إيقافه.

تُنظم الملفات بهذا الشكل:

```text
مسار_التخزين/
└── اسم_القناة/
    └── YYYY_MM/
        └── اسم_الملف_الأصلي.ext
```

تُستبدل محارف Windows غير الصالحة في أسماء القنوات والملفات تلقائيًا.

## التشغيل على Windows من المصدر

ثبّت Python على جهاز البناء أو الاختبار فقط، ثم انقر مرتين على:

```text
scripts\run_windows.bat
```

أو نفّذ يدويًا من PowerShell:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app\web_app.py
```

ستفتح الواجهة في المتصفح تلقائيًا. إذا أردت تشغيل البوت تلقائيًا عند فتح التطبيق، فعّل الخيار المخصص من الواجهة بعد حفظ Bot Token وUser IDs المسموح لهم. صورة `assets/wolf_background.png` مضمّنة في الحزمة وتظهر كخلفية للواجهة وكصورة ترحيبية عند إرسال `/start` للبوت.

## نقطة التشغيل الأساسية للجلسة الواحدة

يحتوي المشروع أيضًا على `main.py` كنقطة تشغيل مستقلة لمن يريد إعداد جلسة Telegram واحدة من طرفية تفاعلية. يتحقق الملف أولًا من الجلسة المحفوظة باسم `tmd_user.session`؛ فإذا كانت موثقة يعيد استخدامها، وإذا لم تكن موثقة يطلب رقم الهاتف ورمز التحقق وكلمة مرور التحقق بخطوتين عند الحاجة، ثم يحفظ الجلسة في مجلد `sessions` بصلاحيات محمية. لا يحفظ الملف رمز التحقق أو كلمة المرور ولا يطبع الأسرار في السجل.

لتشغيله محليًا بعد تثبيت المتطلبات:

```powershell
$env:API_ID="ضع_المعرف_هنا"
$env:API_HASH="ضع_المفتاح_هنا"
$env:PHONE="+00000000000"
$env:BOT_TOKEN="ضع_توكن_البوت_هنا"
$env:ALLOWED_USER_IDS="123456789"
py -3 main.py
```

يتم طلب القيم الحساسة من الطرفية إذا لم تكن في البيئة، وتُخفى المدخلات السرية باستخدام `getpass`. لا تضع القيم الحقيقية في GitHub أو في ملف ZIP. أما خدمة Render الحالية فتستمر في استخدام `scripts/render_start.py` لأنها تشغّل Flask و`/health` وتستعيد الجلسة من سر `TMD_SESSION_B64`؛ ولا ينبغي استبدال أمر Render بـ`main.py` ما لم يُدمج خادم الويب داخله.

## إعداد الحساب

أدخل `api_id` و`api_hash` في الواجهة ثم اضغط حفظ الإعدادات وبدء جلسة Telegram. إذا لم تكن هناك جلسة محفوظة، ستظهر حالة `phone`؛ اكتب رقم الهاتف من الواجهة وأرسله، ثم أدخل رمز Telegram، ثم كلمة مرور التحقق بخطوتين عند طلبها.

يُحفظ `api_hash` ورقم الهاتف وBot Token في ملف env محلي داخل مجلد بيانات المستخدم، وليس في `settings.json`. لا تشارك مجلد البيانات أو ملفات الجلسات.

## تشغيل البوت

يجب أن يكون الحساب الشخصي قد سجّل الدخول أولًا حتى يستطيع المحرك قراءة الروابط الخاصة التي يرسلها البوت. أدخل Bot Token في خانته السرية داخل الواجهة، وأدخل User ID أو أكثر في خانة `User IDs المسموح لهم` مفصولة بفواصل، ثم احفظ الإعدادات واضغط تشغيل البوت. ويمكن تفعيل التسجيل الذاتي الموضح أدناه للحسابات الجديدة.

عند إرسال `/start` من حساب موجود في القائمة تظهر لوحة الأزرار الدائمة. أما الحساب الجديد فيُظهر له البوت User ID الذي استلمه Telegram ويسأله عن الموافقة؛ عند «نعم» يُضاف User ID إلى قائمة السماح ويُحفظ في `settings.json`، وعند «لا» يُرفض الوصول. بعد الموافقة تظهر لوحة الأزرار. يمكن إرسال رابط واحد أو عدة روابط، كل رابط في سطر أو مفصولًا بمسافة:

```text
/info https://t.me/channel/123
     https://t.me/channel/124
/download https://t.me/channel/123 https://t.me/channel/124
/range https://t.me/channel 1 50
/status
```

في الفحص المتعدد يعرض البوت نتيجة مستقلة لكل رابط، ثم يظهر زر تنزيل كل الملفات الناجحة أو أزرار تنزيل منفردة. في التنزيل المتعدد يشغّل النظام معالجين فقط يتقاسمان طابورًا محدودًا، ويعرض شريط تقدم لكل ملف وملخص النجاح والفشل. الحد الأقصى للعملية الواحدة ٢٠ رابطًا، وتُزال الروابط المكررة تلقائيًا.

يفحص `/info` تفاصيل الرسالة والقناة والنوع والحجم والوصف. ينزّل `/download` رسالة واحدة. يفحص `/range` الرسائل من رقم بداية إلى رقم نهاية، وبإدخال البداية `١` والنهاية `٠` يُفحص كل سجل القناة المتاح ثم يظهر تقرير بعدد الرسائل والوسائط. أما النطاق الرقمي المحدد فحده ١٠٠ رسالة في الطلب. يستطيع البوت التعامل مع الروابط العامة وروابط القنوات الخاصة التي يستطيع الحساب الشخصي الوصول إليها، بما في ذلك رابط الموضوع مثل `https://t.me/c/3328229190/168/378?single`؛ يُستخرج رقم الرسالة الأخير `378` ومعرّف القناة `-1003328229190`.

عند اختيار **فحص قناة** يسأل البوت أولًا هل أنت مشترك في القناة. إذا كانت القناة العامة قابلة للقراءة، يمكن اختيار «لا» وسيواصل جلب البيانات دون اشتراك. وإذا احتاج الوصول إلى عضوية، يعرض خيار الانضمام بعد موافقة المستخدم، ثم يعيد التحقق. لا ينضم النظام إلى قناة خاصة تحتاج موافقة إدارية ولا يتجاوز صلاحيات Telegram.

تستمر صلاحية التسجيل الذاتي عشر دقائق فقط من لحظة `/start`، ولا يعتمد البوت على اسم المستخدم؛ بل على User ID الرقمي الذي يرسله Telegram. إذا أردت إبقاء البوت خاصًا تمامًا، اترك التسجيل الذاتي غير مستخدم واعتمد على قائمة User IDs اليدوية.

بعد فحص الرابط تظهر معلومات القناة والرسالة والحجم والنوع والوصف، مع زر مباشر لتنزيل الملف. ينزل الملف إلى مسار التخزين، وينظمه داخل مجلد القناة والشهر، ثم يعيده مع معلومات القناة ورقم الرسالة والحجم. المستخدمون غير الموجودين في قائمة السماح يُرفضون.

يحافظ اسم الملف الخارجي على الاسم الأصلي وامتداده كما أرسلهما Telegram قدر الإمكان؛ فلا يُضاف الوصف أو رقم الرسالة إلى الاسم. عند تكرار الاسم داخل مجلد القناة والشهر، تُستخدم لاحقة تصادم تقنية فقط حتى لا يُستبدل ملف بآخر.

يُعرض الوصف السياقي منفصلًا في نتيجة الفحص وتعليق الملف المُرسل. تبدأ الأولوية من نص/وصف الرسالة التالية، وإذا كانت الرسالة التالية ملفًا يُؤخذ وصفها أو اسمها الأصلي أو نوعها، ثم يستمر البحث في الرسائل اللاحقة حتى العثور على وصف نصي. وتوجد امتدادات احتياطية للصور والفيديو والصوت والرسائل الصوتية والفيديو الدائري والرسوم المتحركة والمستندات.

للحصول على User ID استخدم معرفًا معروفًا لحسابك، ولا تعتمد على اسم المستخدم وحده في صلاحيات البوت.

## الأتمتة والإصدار

رقم الإصدار الحالي هو `3.1.0`. حُفظت النسخة السابقة في مجلد مستقل باسم `telegram-media-downloader-suite-v3.0.0-before-3.1.0` قبل بدء هذا التحديث. للاطلاع على قائمة الميزات وخطة التطوير افتح `AUTOMATION_25_FEATURES_AR.md`.

عند تنزيل عدة وسائط أو روابط، يعمل معالجان فقط مع طابور محدود. إذا فشل عنصر واحد، يستمر الآخرون ويظهر السبب والإصلاح في التقرير. لا تُنشأ جلسة Telegram ثانية.

## بناء ملف EXE

على جهاز Windows نفّذ:

```text
scripts\build_windows.bat
```

سينتج الملف:

```text
dist\TelegramMediaSuite\TelegramMediaSuite.exe
```

انسخ المجلد كاملًا إلى جهاز التشغيل. جهاز التشغيل لا يحتاج إلى Python، لكن أول إعداد للحساب يجب أن يتم من الواجهة. ملف `.env.example` مجرد قالب؛ لا تعِد تسميته إلى `.env` داخل الأرشيف قبل التوزيع ولا تضع التوكن أو مفاتيح API في الحزمة.

ملف البناء الحالي ينتج نسخة مجلدية مستقرة. عند الحاجة إلى ملف واحد فقط، يجب اختبار PyInstaller على Windows لأن Pyrogram والملفات المحلية والجلسات تحتاج إعدادًا خاصًا، ولا ينبغي تضمين الأسرار داخل EXE.

## اختبار المطور

```bash
python3 -m py_compile app/config_store.py app/downloader.py app/bot_service.py app/web_app.py
```

اختبار HTTP المحلي يتطلب تشغيل الخادم ثم فتح:

```text
http://127.0.0.1:8765/
```

## حدود النسخة الأولية

النسخة الحالية تنزل رابط رسالة واحدة في كل مهمة. يمكن توسيعها لاحقًا إلى اختيار عدة روابط، قائمة قنوات، تنزيل دفعي، استئناف دقيق، إحصاءات إجمالية، وتغليف Windows بمثبت. لا تعرض الواجهة الأسرار في الحالة أو السجل، ولا تحفظ رمز التحقق أو كلمة مرور التحقق بخطوتين.
